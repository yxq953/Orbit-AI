# 打印文档

## Overview

本机固定打印机：`NPI689498 (HP LaserJet MFP M233dw)`。

所有打印都走 `scripts/print.py`（绝对路径
`D:\dsh\.claude\skills\print\scripts\print.py`）。它自建 GDI 打印机 DC 排版：
文本用 `微软雅黑` 直接 `TextOut`，PDF 用 PyMuPDF 光栅化、图片用 Pillow 加载，
再经 `PIL.ImageWin.Dib.draw()` 画到 DC 上。**全程无 GUI 对话框**，可无人值守。

依赖已装：`pywin32`、`PyMuPDF`、`Pillow`。

## 铁律

1. **不要 shell out 到别的应用。** 不要用 `Start-Process -Verb Print/PrintTo`、
   Acrobat `/t`、Edge、`Out-Printer`、`Get-Content | Out-Printer`。
   - `-Verb Print` 和 `Out-Printer` 只发给**系统默认打印机**，不是指定那台。
   - Acrobat / Edge 会弹窗或挂住不退出，agent 拿不到完成信号。
   - `Out-Printer` 打中文会变乱码。
2. **永远显式指定打印机名**，不要依赖默认打印机。
3. **发完必须验证。** `EndDoc()` 不报错 ≠ 打印成功，只是进了后台队列。
4. 用户已明确要求**直接打印、不问确认**。但打完必须如实汇报页数和真实结果。

## 快速参考

下表里 `$P` = `D:\dsh\.claude\skills\print\scripts\print.py`（**用绝对路径**，
不要用相对路径，工作目录不一定是 D:\dsh）。

| 任务 | 命令 |
|---|---|
| 打一行字 | `python $P text "中华人民万岁" --size 72` |
| 打文件（可多个） | `python $P file <路径> [<路径>...]` |
| 多份 | 加 `--copies 3` |
| 只打某几页 | 加 `--pages 1,3-5`（只配单个 PDF/doc/docx） |
| 页脚页码 | 加 `--page-number 1`（默认隔页打，编号从 1 起） |
| 页脚带标题 | 加 `--page-number 1 --title "文章标题"` → `文章标题 \| 1` |
| 每页都要页码 | 再加 `--page-number-step 1` |
| 双面 | 加 `--duplex long`（长边/书）或 `short`（短边/台历） |
| 先看多少页 | 加 `--dry-run`（不发送任务） |
| 查打印机/队列 | `python $P status` |
| 列所有打印机 | `python $P list` |
| 换目标打印机 | 加 `--printer "<名字或子串>"` |

`--dry-run` / `--copies` / `--printer` / `--wait` 放在子命令**前面或后面都可以**。

`--printer` 支持子串匹配，但**必须够具体**：写 `"HP"` 会同时命中
`HP LaserJet MFP M233dw` 和 `HP Smart Tank 530 series [F5FE4B]` 两台机器而报错退出；
用 `"LaserJet"` 或 `"M233dw"`。失败时退出码非 0，stderr 上是中文错误信息，
原样读给用户。`--wait` 默认 60 秒（打印后等队列清空的时长）。

## `--pages` 页码范围

语法：`1`、`3-5`、`2-`（到末页）、`1,4,7-9`。1 起算，按你写的顺序去重。

以下情况脚本一律**报错退出**，绝不静默猜：

- **只配单个文件**。多文件会被拒，改成分多次调用。
- **只对 `.pdf` / `.doc` / `.docx` / `.rtf` 有效**。文本文件是重新排版分页的，
  你心里的"第 3 页"和实际页对不上，所以直接拒绝。
- **超出页数**：报错并告诉你共几页。显式写的上界也算 —— 3 页的文件写 `2-9`
  会报错，不会静默截断；只有开区间 `2-` 才表示"到末页"。
- **空值**：`--pages ""` 会被拒。空值会被当成"不过滤"而打掉整份文件，
  宁可报错也不要多打一叠纸。算出来的范围为空时，别硬传空串。
- 写 `1-2`，不要写 `-2`。

## `--page-number` 页脚页码

`--page-number N` 在**底部靠右**打页码，从 N 开始递增。
配上 `--title "文章标题"` 就变成 `文章标题 | 页码`。

**默认是隔页打**：第 1、3、5… 个**打印页**有页脚，第 2、4、6… 个不打。
编号只在有页脚的页上递增，所以双面打印时正好是**每张物理纸正面一个编号**：

```
双面 4 页，--page-number 6
  第1张 正面 → 6      第1张 背面 → 无
  第2张 正面 → 7      第2张 背面 → 无
```

想改节奏就加 `--page-number-step K`：每隔 K 个打印页打一次，
`--page-number-step 1` 就是**每页都打**（6,7,8,9…）。

其余规则：

- **不给 `--page-number` 就完全不打页脚**，这是默认行为。
- `N` 必须 **≥ 1**。想接着上一批的编号继续打就填那个数（比如上次打到 46，这次填 47）。
- `--title` 必须配 `--page-number`，且不能是空串、不能含换行 ——
  三种都会被明确拒绝，脚本不猜你想从几开始。只想要纯页码就别给 `--title`。
- `--page-number-step` 同样必须配 `--page-number`，否则报错
  （没打页脚时它没有意义）。
- 编号是**按实际打印出来的整条页流**数的，不是原文档页码。所以：
  - `--pages 5-10 --page-number 1` 打出来是 1,2,…，不是 5,6,…。
  - 多个文件一起打时**跨文件连续**。
  - **多份（`--copies`）时跨份连续** —— 3 页打 2 份就是一条 6 页的流，
    编号 1,2,3。这是必须的：若每份各自重排，奇数页数的文档双面时
    编号会跑到纸背面上（代价见下文的"共用纸张"说明）。
- 正文会自动给页脚让位，**没页脚的那几页也一样让位**，
  这样正反面行数一致、排版不跳。文本按页减少行数、PDF/图片等比缩小。
- 标题太长时自动从左截断加省略号，右边的页码始终保留、不会画到纸外。

### 和双面配合的注意事项

编号落在纸**正面**还是**背面**，只看 step 的奇偶（偶数流位 = 纸正面）：

| `--page-number-step` | 双面时的落点 |
|---|---|
| `2`（默认） | 每张纸的**正面**，正好一纸一号 ✅ |
| 其他**偶数**（4、6…） | 仍然只落在纸正面，只是编号更稀 ✅ |
| `1` | 每页都有编号 —— 正反面都有，本来就是你要的 |
| **奇数 ≥3** | **部分编号会落在纸背面上**，和正反面错位 ⚠️ |

奇数 step ≥3 这种事脚本会在输出里打一行 `警告` 提醒；step=1 是特例，不警告。

**单面打印时默认隔页打会跳号**：4 张纸只有第 1、3 张有编号，显示 1、2。
单面想每页都编就加 `--page-number-step 1`。

**双面 + 多份 + 奇数页数时，相邻两份会共用纸张**：编号是跟着整条页流走的，
所以 3 页打 2 份双面会得到 3 张纸，其中第 2 张的正面是第 1 份的最后一页、
背面是第 2 份的第一页 —— **两份没法各自抽出来单独装订**。
这是双面打印按页流配对的固有结果，不是 bug。要能分开就单面打，
或者一份一份地打。

## `--duplex` 双面

- `--duplex long` 长边翻转，像书一样左右翻 —— 竖版文档一般用这个。
- `--duplex short` 短边翻转，像台历一样上下翻 —— 横版表格、PPT 讲义用这个。
- 不传就是单面。

打印前会查驱动是否支持；不支持会直接报错，而不是悄悄给你单面。
`--dry-run` 里的张数是**纸数**不是页数：3 页双面 = 2 张。

支持格式：文本（`.txt .md .csv .json .py` 等）、`.pdf`、
图片（`.png .jpg .bmp .gif .tif .webp`）、`.doc .docx .rtf`。

## 汇报格式

把 `print.py` 输出如实转述：页数 × 份数、任务号、`结果` 那一行。三种结果要分清：

- `任务已离开队列，打印机状态 …` → 已送达打印机
- `超时，任务仍在队列 …` → 还在排队或卡住，把 pending 状态一并告诉用户
- `提交后队列里没看到对应任务` → **未证实**，不要说"打印成功"

## 常见错误

| 错误做法 | 后果 | 正确做法 |
|---|---|---|
| `Start-Process -Verb Print` | 打到默认打印机，不是 HP 那台 | 用 `print.py` |
| Acrobat `/t` 打印 PDF | 弹窗、可能挂住、无完成信号 | 用 `print.py`，离线光栅化 |
| `Out-Printer` 打中文 | 乱码 | 用 `print.py` |
| 只回"已发送打印任务" | 用户以为纸出来了 | 报 `--wait` 的队列验证结果 |
| 路径没确认就硬跑 | 报错或空任务 | 先确认文件存在 |

## 注意事项

- PDF 光栅化默认 **600 dpi**（打印机驱动的最高档，与 DC 的 600×600 对齐）。
  位图会**先缩到目标矩形大小**再交给 GDI（见下一条），存留的每页约 **89 MB** ——
  实测 6 页 ≈ 0.56 GB、**24 页 ≈ 2.1 GB**。
  所以 **超过 20 页就主动降 `--dpi 200`**（每页约 15 MB）。
  单页、几页的简历/文件用默认 600 就很好，不用动。
- **图片必须先缩到目标矩形再画，不能直接把大图丢给 GDI。** 位图远大于目标矩形时，
  GDI 往**打印机 DC** 记录 EMF 会**静默失败**：任务 spool 出 0 字节、整页空白，
  而且不报任何错。内存 DC 不受影响（直写位图、不走 EMF），所以**离屏自测发现不了
  这个坑** —— 验证打印链路要看 spool 字节数，或直接出纸。
- 纸张 A4（DEVMODE 实测 `PaperSize=9`，可打印区 201.5 × 288.5 mm）。
- `--margin` 取值 **0~80 毫米**，默认 15。负边距会把内容推出纸外、
  太大则没地方排内容（文本会碎成几千页），所以两头都会被拒绝。
- 文件**按内容认，不只按扩展名**：内容是 PDF 就按 PDF 打（改名成 `.txt` 也对）；
  二进制文件冒充文本、损坏的 PDF/图片会被拒绝，不会打出乱码或空白页。
- 内容全空白时直接拒绝 —— 打出来就是一张白纸，那是浪费。
- `.doc/.docx/.rtf` 走 WPS COM 转 PDF，首次调用会拉起 WPS，
  要十几秒，**不是卡死**，别中途打断。
- 文本文件默认 12pt、按页自动分页；超长行按词换行。
  横幅文字默认 48pt 居中，过宽会自动缩字号（输出里会提示）。
